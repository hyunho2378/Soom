# IA.md — 화면 구조와 플로우

## 화면
1. 입장 화면 (#joinScreen)
   - 방 이름, 내 이름 입력 후 입장. 계정 없음.
2. 회의실 화면 (#roomScreen)
   - 상단 헤더: 방 이름, 참가자 수, 나가기.
   - 탭 전환: 실시간 화면 / 실습 기록물.
     - 실시간 화면(#panelLive): 큰 뷰어 + 내 화면 공유하기 / 공유 중지.
     - 실습 기록물(#panelRecords): 올리기 폼 + 카드 목록 + 전체 초기화.
   - 우측(모바일에서는 상단): 참가자 패널(발표 중 표시).
3. 오버레이
   - 이미지 확대 라이트박스(#lightbox).
   - 초기화 확인 모달(#resetModal).

## 플로우
- 입장: 방 이름 + 이름 → WebSocket join → records-init 수신 → 회의실 진입.
- 발표: 실시간 화면 탭에서 내 화면 공유하기 → 방 전원에게 P2P 송출. 다른 사람이 공유 시작하면 이전 발표자 자동 중지.
- 기록물: 실습 기록물 탭 → 항목 선택 + 요약 + 이미지 첨부 → 올리기 → 방 전원 카드 실시간 반영. 다른 탭에 있으면 탭 배지로 새 기록물 알림.
- 초기화: 진행자가 전체 초기화 → 확인 문구 초기화 입력 → 방 전원 목록 비움.

## 명명 규칙
- 상위 개념(실시간 화면 / 실습 기록물)과 하위 항목 이름이 겹치지 않게 둔다.
- 라벨은 능동태(입장하기, 내 화면 공유하기, 공유 중지, 기록물 올리기, 이미지 첨부하기, 초기화하기).
