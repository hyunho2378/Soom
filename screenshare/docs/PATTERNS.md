# PATTERNS.md — 반복 패턴

## 카드
- 기록물 카드는 좌측 4px 액센트(트랙 A 파랑 / 트랙 B 주황) + 항목 배지 + 작성자 + 시각 + 요약(개행 보존 pre-wrap) + 이미지 그리드.

## 폼
- 라벨은 필드 위 form-label. 이름은 입장 시 값 재사용(수정 불가 표시). 항목은 커스텀 드롭다운(네이티브 select 미사용, 트랙 색 점 포함).
- 제출 전 클라 검증: 항목 미선택 또는 (요약 없음 + 이미지 0장) 시 인라인 에러. 서버도 동일 검증(이중 방어).

## 모달
- 초기화는 확인 문구 초기화를 정확히 입력해야 버튼 활성화. 바깥 클릭·취소·Escape로 닫힘.

## 빈 상태
- 기록물 없음: recordsEmpty 안내 문구. 첫 카드가 오면 자동 숨김.
- 발표자 없음: 뷰어 placeholder 표시.

## 에러
- 인라인 상태 텍스트(record-status.error, join hint, reset-status). 팝업 최소화.

## 로딩
- 업로드 중 제출 버튼 비활성 + 올리는 중입니다 상태. 완료 시 폼 초기화.

## 실시간 반영
- 서버가 방 전원(작성자 포함)에게 record-added 브로드캐스트 → 카드는 항상 WS 수신으로만 그린다(작성자가 로컬로 미리 그리지 않아 중복 없음).
- 뒤늦게 입장하면 records-init로 기존 기록을 한 번에 받는다.
